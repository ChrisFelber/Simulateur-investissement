# Simulateur d’investissement

Nouvelle version du simulateur d’investissement, construite en HTML, CSS et JavaScript vanilla et prévue pour GitHub Pages.

## Structure

- `index.html` : structure de la page
- `css/styles.css` : styles responsive et thèmes
- `js/config.js` : configuration et valeurs par défaut
- `js/simulation.js` : calculs financiers
- `js/chart.js` : graphique d’évolution
- `js/i18n.js` : traductions FR / DE / EN
- `js/app.js` : état et interactions de l’interface

## Valeurs par défaut prévues

- Capital initial : CHF 5’000
- Versement : CHF 100/mois
- Rendement annuel : 3,5 %
- Durée : 10 ans
